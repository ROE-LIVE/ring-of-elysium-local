# W17: модули с земли и отметки попаданий2022

Новая проверка только двух исправлений. Прошлые проверки полного матча повторять не требуется. Новый пакет ещё не подтверждён запуском Windows; Proton — отдельный контроль.

1. Закрыть предыдущую игру/launcher, выполнить `git pull --ff-only` в `ring-of-elysium-local`.
2. Запустить `.\play.cmd -Client "G:\REsearch\Ring of Elysium-2022"`. Клиент используется на месте, без копии/бэкапа; EXE/DLL/архивы не патчатся. Дождаться готовности, войти через Training и оставить DEFAULT.
3. Для каждогоID записать «прошёл / ошибка / не проверял», действия и время. Один короткий видеозапись прицела полезнее ожидания звука в журнале.

| ID | Действие | Ожидается |
| --- | --- | --- |
| W17-01 | Взять M4/5.56. ОткрытьTab и перетащить совместимый коллиматор с земли прямо на его оружейный слот | Модуль появился на M4, исчез с земли; промежуточный перенос в сумку не нужен |
| W17-02 | Аналогично установить AR-магазин и AR-глушитель | Магазин/глушитель установлены, не дублируются на земле; послеR вместимостьM4до40, общее число патронов сохраняется |
| W17-03 | Попытаться поставить SR-глушитель на M4 | Несовместимый предмет не устанавливается и не пропадает |
| W17-04 | Сделать один выстрел, выбросить M4 и подобрать в другой слот | Тот же текущий clip и установленные модули, без восстановления патронов |
| W17-05 | Несколько раз попасть в туловище мишени; затем выстрелить мимо | На попаданиях короткие черточки и характерный звук; на промахе их нет. По броне возможен оранжевый вариант |
| W17-06 | Прицельно попасть в голову | Вариант отметки и звук головы. Это проверкаfeedback, не повышенного урона: баланс пока учебный |
| W17-07 | Добить мишень | На последнем принятом попадании красная отметка, мишень погибла; повторные выстрелы по телу не дают нового убийства |

Если не видноM4/мишени: сначала записать клетку/положение; не считать отсутствие предметов при другом спавне результатом теста переноса. Не ждать2цвета на одном попадании: смерть имеет приоритет над бронёй. Если не слышно звук, указать устройство/громкость и есть ли звуки обычной стрельбы.

После выхода: `.\export-report.cmd`. Передать папку `reports/<ID>` и ответыW17; полные `runs`, ключи и raw AUTH не публиковать. Добавить commit (`git rev-parse --short HEAD`) иWindows/GPU. ПолныйW16остаётся исторической проверкой, запускать его заново радиW17не нужно.
