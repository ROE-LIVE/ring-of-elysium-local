# Фиксированные данные локального протокола

По прямому указанию владельца в этот публичный комплект включены только:

- `candidate-001.key`:16байт сессионного AES-ключа локального эмулятора. Восстановлен в исследовании session-06-review из состояния qapi клиента; проверен на331DT/4DC и CK четырёх локальных соединений.
- `lobby-ck.bin`:32байта существующего CK payload из MIT LobbyPreData.cs старого run_roe_2022. Ответ установки ключа вынесен из исходника в этот файл, чтение относительно корня репозитория.

Это согласованная пара фиксированного handshake нашего стенда. Она не заменяет пароль Steam и не является универсальным ключом серверов ROE. Смена handshake потребует заново проверить соответствие. Источник: исходный ROE_SERVER/research/builds/2022/session-06-review/report.md; публичная сводка в исследовательском репозитории.

Остальные ключи/билеты/пароли/данные аккаунтов и private-файлы публиковать запрещено. Не печатайте значения в отчётах. Обоим включённым файлам назначен binary Git attribute; контрольные суммы записаны в SOURCE-MANIFEST.json. Обычный clone/pull получает всё необходимое для локального протокола.
