# Изменение и проверка

Рабочий код запуска/эмулятора держим в ring-of-elysium-local. Исследования и CSV — в ring-of-elysium-research. Перед изменением установите билд/SHA, прочитайте ограничения в README. Изменяйте одну механику за раз; сохраните последовательность событий и отрицательный контроль. Новую клиентскую команду сначала подтвердите декодером/обработчиком и адресом.

```bash
python -m pip install -r requirements.txt
python -B -m unittest discover -s tests -v
dotnet build server/lobby/LobbyEmulator.Sdk/LobbyEmulator.Sdk.csproj -c Release
```

Тесты и сборка не требуют настоящих ключей и не запускают игру. Для `--verify-only` launcher пока требует локальные зависимости. Зависимости устанавливаются в выбранную Python-среду; можно использовать venv.

Публичный launcher по указанию владельца использует выбранную папку на месте без копии/бэкапа. EXE/DLL/архивы не патчить; записывать исходные хеши и удалять только собственные debug-файлы. Сервисы localhost. В PR: проблема, воспроизведение, до/после, тесты, ограничения. Не включайте private, raw AUTH, клиент, дампы и пользовательские runs. Для отчёта используйте экспорт allowlist. Новая формула учебного урона не становится исходной формулой игры от того, что проходит тест.

Исключение для публикации: только фиксированные private/candidate-001.key16 и private/lobby-ck.bin32 в ring-of-elysium-local разрешены владельцем. Любые остальные private и учётные данные не добавлять.
