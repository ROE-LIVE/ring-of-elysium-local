# Одна проверка нового комплекта

Команда: `.\play.cmd`, затем указать папку игры. Клиент используется на месте, без копии/бэкапа. Training, клетка DEFAULT.

| Действие | Ожидается |
| --- | --- |
| Войти на зимнюю карту | Можно ходить; стартовый Glock и планер |
| Подобрать два тестовых оружия/патроны | Три отдельных слота; переключение1/2/3 |
| Выстрелить и перезарядить неполный магазин | Clip увеличился, резерв уменьшился; полная R пока может анимироваться |
| Подойти к тросу в безопасном регионе и подняться | Учебный невидимый прямоугольник не отнимаетHP |
| Сесть и завершить матч | Rescued1; Kill зависит от действий в этом матче |

После выхода: `export-report.cmd`. Укажите commit (`git rev-parse --short HEAD`), Windows/GPU, последовательность действий, ожидание/факт и время события. Не повторяйте весь список механик, если проверяете только безопасность эвакуации.

Для новых исправлений16.10 используйте отдельный [W17](WINDOWS-TESTS-W17.md): прямой монтаж модулей, drop/repick и hitmarker/sound. Старые тесты целиком повторять не требуется.
